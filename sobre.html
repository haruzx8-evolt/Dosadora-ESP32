Sobre o Projeto

Dosadora automática de materiais granulares com ESP32

O que é

Sistema de dosagem automática desenvolvido com ESP32, que utiliza uma célula de carga (HX711) para medir o peso do material em tempo real e controla uma bomba/rosca sem-fim e um servo motor para liberar a quantidade exata configurada pelo usuário. O controle e o monitoramento são feitos remotamente por este site, que se comunica com o ESP32 através de uma API REST na rede local.

Microcontrolador
ESP32
Sensor de peso
Célula de carga + HX711
Atuadores
Bomba/rosca + Servo
Comunicação
Wi-Fi / REST API
